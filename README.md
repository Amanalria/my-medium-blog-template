# Medium Blog CMS Template (Pristine Edition)

A minimalist, high-performance Medium publication clone and CMS Studio.

## Features
- **Zero Dummy Data**: Clean template with 0 dummy articles, 0 fake authors, and empty categories.
- **WordPress Classic WYSIWYG Editor**: Live domain/slug generator, tag manager, reading time estimator.
- **Dynamic Category & Story Management**: Create, edit, and delete topics and articles on the fly.
- **Supabase Cloud Native**: Instant integration with Supabase PostgreSQL for articles, settings, and subscribers.
- **Theme Switcher**: Zero-FOUC Light and Dark modes.
- **SEO & Social Share Ready**: Auto-generated meta tags, WhatsApp, X, and Facebook sharing.
